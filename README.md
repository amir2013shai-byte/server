# ⚔️ Королевские Схватки

Мобильная 3D-игра в жанре карточных башенных боёв (в духе Clash Royale) с:

- **полным ростером карт** — войска, духи, заклинания, здания, легендарные архетипы;
- **конструктором своих карт** — HP, урон, скорость, дальность, стоимость, редкость;
- **настройкой абилок** — щит, заморозка, цепная молния, вампиризм, разгон, аура лечения, призыв войск, урон при гибели и др.;
- **встроенным 3D-редактором моделей** — примитивы (куб, сфера, конус, капсула…), цвета, свечение, повороты, шаблоны;
- **боем против ИИ** — эликсир, мосты, башни, двойной эликсир, короны.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Сборка APK

См. [APK_BUILD.md](./APK_BUILD.md) — упаковка через Capacitor в нативный Android-APK.

## Структура

```
src/
  data/cards.js        — все карты (статы, абилки, модели)
  data/models.js       — построители 3D-моделей из примитивов
  game/engine.js       — боевой движок (симуляция)
  game/ai.js           — ИИ-соперник
  render/battleView.js — 3D-вид битвы (Three.js)
  render/modelEditor.js— 3D-редактор моделей
  ui.js                — экраны интерфейса
```

Все названия, описания, характеристики и 3D-модели — оригинальные.
