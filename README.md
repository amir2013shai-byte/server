# ⚔️ Королевские Схватки

Мобильная игра в жанре карточных башенных боёв (в духе Clash Royale) с:

- **полным ростером карт** — войска, духи, заклинания, здания, легендарные архетипы;
- **конструктором своих карт** — HP, урон, скорость, дальность, стоимость, редкость, 19 абилок;
- **рисованием карт от руки** — кисть, ластик, штампы, кадры и анимация (покачивание, пульс, дрожь, вращение, смена кадров);
- **прокачкой карт** — уровни 1–13, для апгрейда нужны золото и копии именно этой карты (копии падают из сундуков);
- **режимами боя** — обычный (рейтинг), дружеский, внезапная смерть, ×2 эликсир, черновик, турнир;
- **сетевым боем 1×1** — по коду комнаты через свой релей (см. [NETPLAY.md](./NETPLAY.md));
- **друзьями, кланами, клановой войной**, лигами, сезонами, реплеями боёв;
- **админ-панелью** — баланс карт и публикация карт для всех игроков.

## Правила арены

- Войска и здания ставятся **только на свою половину**;
- Заклинания можно бросить **на любую точку арены**, включая территорию врага;
- Главная башня **спит**, пока её не разбудят: урон по ней или гибель боковой башни;
- HP башен всегда видно над ними.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
node tools/net/relay.mjs --port 8787   # релей для сетевого боя (опционально)
```

## Структура

```
src/
  data/cards.js        — все карты (статы, абилки, спрайты из моделей)
  game/engine.js       — боевой движок (симуляция)
  game/ai.js           — ИИ-соперник
  render/battleView.js — 2D-вид битвы (canvas)
  render/art2d.js      — рисунки карт, спрайты, анимация
  render/artEditor.js  — редактор рисунка карты
  progress.js          — золото, копии карт, уровни, сундуки, лиги
  net.js               — сетевой бой (хост-гость)
  ui.js                — экраны интерфейса
```

Все названия, описания, характеристики и графика — оригинальные.
